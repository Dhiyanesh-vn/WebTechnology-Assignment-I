# Web Technology Assignment I – U21CS501

This repository contains the complete HTML5, CSS3 and JavaScript implementation for all five scenarios in Assignment I.

## Scenarios
1. Web fundamentals – Internet, networks, URL, domain, browser/server, website workflow, client/server scripting.
2. Student admission form – HTML5 controls, input types, image/video/audio, CSS3 selectors, box model and responsive design.
3. Fashion store homepage – backgrounds, borders, text effects, animation, multi-column layout and UI principles.
4. Grade calculator – five-subject total, average, grade and pass/fail using JavaScript.
5. Supermarket billing – three products, quantity × price, 10% discount above ₹2000 and final payable amount.

## Files
- `index.html` – project home page
- `q1_web_concepts.html` to `q5_billing.html` – scenario pages
- `styles.css` – common responsive styling
- `script.js` – Q4 and Q5 JavaScript logic
- `assets/` – local media used by Q2
- `screenshots/` – browser output screenshots

Open `index.html` in a browser to run the project.
