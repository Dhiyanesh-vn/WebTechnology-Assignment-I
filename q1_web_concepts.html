A compact visual guide to the fundamental concepts needed before developing an institutional website.

1. Internet Overview

The Internet is a global network of interconnected computer networks that exchange data using standard communication protocols such as TCP/IP. The Web is a service that runs over the Internet using browsers, web servers and HTTP/HTTPS.

2. Fundamental Computer Network Concepts

IP Address

Identifies a device/interface on a network.

Protocol

A set of rules for communication, such as TCP/IP and HTTP.

Router

Forwards packets between different networks.

DNS

Translates domain names into IP addresses.

4. Domain Name

A domain name is a human-readable address used to reach a website. DNS resolves the name to an IP address so the browser can locate the server.

5. Web Browsers and Web Servers

Browser

Requests resources, interprets HTML/CSS/JavaScript and displays the user interface.

Web Server

Receives HTTP requests and returns webpages, files or generated responses.
